# Yogesh M Narvade | Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript.

## Included
- Dark navy and cyan visual identity
- Responsive single-page navigation
- Split hero with the YN logo
- About, Education, Skills, Projects, Certifications and Contact sections
- Mobile navigation and scroll reveal effects
- StudyMate clearly marked as a planned project

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Copy the contents of this folder into the root of your GitHub Pages repository.
2. Commit and push to the `main` branch.
3. In repository Settings → Pages, select `main` and `/ (root)` if not already configured.
4. Wait for the Pages deployment to complete.

## Before publishing
- Review all personal details and links.
- Add certificate preview/verification links only after preparing documents for public sharing.
- Add StudyMate screenshots, repository and demo only after the project exists.
- Add a resume link when your resume is ready.

## Files
- `index.html` – page content
- `style.css` – layout, colors and responsive styles
- `script.js` – mobile navigation, scroll reveal and active section navigation
